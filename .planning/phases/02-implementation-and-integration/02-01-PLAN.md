1. Add helper function for expected_url validation (in send-interactive-authorization-request.ts):
   ```typescript
   export interface ValidateOpenid4vpExpectedUrlOptions {
     /**
      * The OpenID4VP request from the IAE response
      */
     openid4vpRequest: Openid4vpRequest

     /**
      * The URL where follow-up request will be sent
      * (typically the interactive_authorization_endpoint)
      */
     followUpRequestUrl: string

     /**
      * Callbacks for JWT verification
      */
     callbacks: Pick<CallbackContext, 'verifyJwt'>

     /**
      * JWK or JWK set for verifying the signed request
      */
     signerJwk?: Jwk | JwkSet
   }

   export interface ValidateOpenid4vpExpectedUrlResult {
     valid: boolean
     error?: string
     errorDescription?: string
   }
   ```

2. Implement validateOpenid4vpExpectedUrl function:
   - If `openid4vpRequest.request` is undefined (unsigned), return `{ valid: true }` (PROT-06)
   - Decode the JWT from `openid4vpRequest.request`
   - Extract `expected_url` claim from payload
   - If `expected_url` is missing in signed request, return error (PROT-05)
   - Compare `expected_url` to `followUpRequestUrl` (exact string match)
   - If mismatch, return `{ valid: false, error: 'invalid_request', errorDescription: 'expected_url mismatch' }` (VP-04)
   - If match, return `{ valid: true }`

3. Add helper function for encoding OpenID4VP response (VP-05, VP-06):
   ```typescript
   export interface EncodeOpenid4vpResponseOptions {
     /**
      * The VP response to encode
      */
     vpResponse: {
       vp_token: string
       presentation_submission?: unknown
     }

     /**
      * Response mode from the OpenID4VP request
      */
     responseMode: 'iae_post' | 'iae_post.jwt'

     /**
      * Encryption key from AS (required for iae_post.jwt)
      */
     encryptionKey?: Jwk

     /**
      * Callbacks for encryption
      */
     callbacks?: Pick<CallbackContext, 'encryptJwe'>
   }
   ```

4. Implement encodeOpenid4vpResponse function:
   - VP-05: For `iae_post`, return `JSON.stringify(vpResponse)`
   - VP-06: For `iae_post.jwt`, encrypt the response:
     - Require encryptionKey and callbacks.encryptJwe
     - Use JARM encryption (per OpenID4VP Section 8.3)
     - Return encrypted JWT string
   - Export function for wallet implementations

5. Export the functions and types from the module.

6. Update zOpenid4vpRequest schema to document expected_url:
   - Add comment explaining expected_url is in the signed JWT, not top-level

NOTE: These functions are for WALLET use - the wallet calls validateOpenid4vpExpectedUrl to validate the AS's OpenID4VP request before responding, and encodeOpenid4vpResponse to properly encode the VP response.
